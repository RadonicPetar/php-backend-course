# PHP Basics

Examples and exercises from the introductory part of the course, held in March 2026.

| Folder | Topics |
| --- | --- |
| `html-introduction/` | Introductory HTML pages and forms |
| `introduction/` | First PHP scripts and PHP page templates |
| `variables/` | Variables and basic data handling |
| `operators/` | Operators |
| `conditionals/` | Conditional expressions, if and switch |
| `strings/` | String handling |
| `dates/` | Dates |
| `loops/` | For, while, and do-while loops |
| `arrays/indexed/` | Introductory and follow-up indexed array examples |
| `arrays/associative/` | Associative arrays |
| `arrays/multidimensional/` | Multidimensional arrays |
| `functions/` | Functions, references, and recursion |
| `file-handling/` | Files and JSON data |
| `forms/get/` | GET forms |
| `forms/post/` | POST forms and uploads |
| `sessions/` | Sessions and the accompanying product exercise |

Original code and supporting assets are preserved. Run each example separately; these folders are not one combined application.
